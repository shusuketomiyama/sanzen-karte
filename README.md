# 産前産後カルテ（iPad用アプリ）

産前・産後の整体サロン向けの顧客管理アプリです。顧客リスト、問診票、施術カルテを1つにまとめています。

## 使い方の流れ
1. 初めてのお客様には「📋 新しいお客様（問診票を記入）」からiPadを渡して記入してもらいます。送信するとお客様リストに追加されます
2. 来店されたら、お客様リストでその方をタップします。今日のカルテが開きます（日付・簡単な情報・回数は自動で入ります）
3. 姿勢の写真は「正面・後ろ向き・左向き・右向き」×「施術前・施術後」の枠があり、必要な枠だけタップして撮影します
   - 撮影後に「📐 ライン」を押し、案内に従って耳・肩・骨盤・膝・くるぶしをタップすると、ゆがみのラインと角度が表示されます（点はドラッグで調整、見えない点は飛ばせます）
   - 施術前と後の両方にラインを引くと、角度の変化が並べて表示されます
   - 角度は写真の水平・垂直が基準なので、iPadはできるだけ垂直に構えて撮影してください
4. メモ欄に自由に記入して保存します
5. 保存したカルテは、そのお客様の「これまでの記録・問診票」にたまっていきます

## そのほかの機能
- 施術時の注意（帝王切開、医師からの制限など）を問診票から自動で表示します
- 問診票とカルテを印刷・PDF保存できます。紙用の白紙の問診票もあります
- バックアップをiCloud Driveに保存・復元できます。CSVで書き出すこともできます

## データの保存場所
- データは **iPadの中だけ** に保存され、サーバーには送られません
- そのため、iPadの故障や紛失に備えて **週に1回「設定・バックアップ」→「バックアップを保存」→ iCloud Driveに保存** してください（7日たつとホーム画面でお知らせします）
- iPadには必ずパスコードを設定してください

## iPadへの入れ方
1. このフォルダのファイルを、https で公開できる場所（GitHub Pagesなど）に置きます。ファイルにはお客様のデータは含まれていません
2. iPadの **Safari** でそのURLを開きます
3. 共有ボタン →「**ホーム画面に追加**」を選びます
4. 以後は、ホーム画面のアイコンから起動します。アプリのように全画面で開き、オフラインでも使えます

> Safariのタブで開いた場合と、ホーム画面のアイコンから開いた場合では、保存されるデータが別々になります。必ず **ホーム画面のアイコンから** 使ってください。

## アプリを更新したとき
`sw.js` の `VERSION` の数字を上げてから公開し直してください。次回起動時に新しい版に切り替わります。
